# Ambience assets

Beds for the ambience mixer (ADR-0005). Taxonomy ids are in `src/core/analysis/ambience-taxonomy.ts`.

- `base/`: the procedural base pack, generated by `npm run sounds:build` (`scripts/sounds/build-base-pack.mjs`).
  Checked by `npm run sounds:verify`.
- `real/`: Freesound CC0 beds (A4), named by the category id. Built by `npm run sounds:build-real` from the
  screening records. Only categories whose screen passed are built. Checked by `npm run sounds:verify`.
- `curation/<category>.json`: the top eight CC0 candidates for each category with the score reasons, written by
  `npm run sounds:curate` (search only, no audio). The `screening` key is written by `npm run sounds:screen`
  (A4, see below). Re-curating drops `screening`, so screen again afterwards.
- `curation/overrides.json`: names another candidate for a category, with a reason. It must be a candidate that
  passed the screen. Without an override the build tries the screened candidates in order (the screen's choice,
  then the other passing candidates by CLAP) and takes the first that passes every loudness, peak and seam check.
- `real/manifest.json`: one row per real bed (`source: "freesound"`, with `freesoundId`, `author` and `url`).
- `base/manifest.json`: one row per base-pack bed.
- `LICENSES.json`: the licence ledger. Every bundled file has a row.

Regenerate the packs only through the build scripts. Do not hand-edit the generated files. Freesound scripts
read the key from the environment only: `FREESOUND_API_KEY=$(cat ~/.config/lectio/freesound.key)`. Only sounds
whose licence is exactly `http://creativecommons.org/publicdomain/zero/1.0/` are used. Previews are cached in
`.cache/freesound/`, which is git-ignored.

Each real bed must also have a `require` in `src/audio/ambience-pack.ts`. `sounds:verify` and the
ambience-pack tests check that the list and the manifest agree.

## Screening (A4)

`npm run sounds:screen` (`scripts/sounds/screen-run.mjs`) screens every candidate with:

1. AudioSet tags per second: PANNs CNN14 (`scripts/sounds/screen/tag.py`, pinned in
   `scripts/sounds/screen/requirements.txt`). The venv and model caches live under `.cache/`.
2. The policy (`scripts/sounds/screen-policy.mjs`). A deny family (sirens and alarms, music, voices,
   vehicles, engines, tools, phones and media, thunder, gunfire) must not reach its threshold in any second
   of the window: 0.05 for the alarm family, 0.15 for the rest. Voices are lifted only for crowd-like
   categories. The required sounds of a category must be present in at least half of the window's seconds.
   Exemptions and required sounds are in `scripts/sounds/freesound-targets.mjs`.
3. The cleanest 64 s window: no denied second, required sounds present, then the lowest level variance.
4. CLAP text-audio similarity (`scripts/sounds/screen/clap.py`, `laion/clap-htsat-unfused`) re-ranks the passing
   candidates. The chosen candidate is the highest CLAP score.

The evidence per candidate is kept in its curation record: the top AudioSet classes, the denied maxima with
their seconds, the window, and the CLAP score. A rejected candidate keeps its reason. A category with no
passing candidate is `unfilled` with its reason, and it gets no file.

Tags are cached per Freesound id under `.cache/screen-work/tags/`, so a run that stops part way resumes at the
first clip without a result.

## Eras and sizes (A4)

Every category has an era (timeless, historic, modern or futuristic). A chapter's era comes from the analysis
(`setting.era`). A bed is refused in a chapter whose era does not accept it (`bedFitsEra` in
`src/core/analysis/ambience-taxonomy.ts`). Real beds are AAC-LC 48 kbps mono, 60 s loops, and the real-bed
budget is 24 MB (`MAX_REAL_PACK_BYTES`).

## `base/manifest.json`

A JSON array. Each entry:

```json
{
  "id": "base_rain",
  "file": "base_rain.m4a",
  "durationMs": 60093,
  "loopStartMs": 46.44,
  "loopEndMs": 60046.8,
  "lufs": -27.6,
  "bytes": 493423,
  "sha256": "<64 hex chars>",
  "kind": "bed",
  "source": "procedural",
  "recipeVersion": "base-pack-v1"
}
```

`file` is relative to `base/`. `lufs` is the integrated loudness measured after normalization.

**Loop region.** Each procedural file holds 46.44 ms of loop audio before and after the loop. The
encoder needs those rolls to avoid an onset at its edges. Players must loop only
`[loopStartMs, loopEndMs)`: start there, and on reaching `loopEndMs` seek back to `loopStartMs`.
Playing the whole file would play the rolls and click at each wrap. `durationMs` is the full file length.

## `LICENSES.json`

A JSON array of ledger rows, one per bundled file:

```json
{
  "id": "base_rain",
  "file": "base_rain.m4a",
  "license": "Proprietary (generated in-house)",
  "source": "scripts/sounds/build-base-pack.mjs",
  "author": "Lectio",
  "date": "2026-10-11"
}
```

Sampled sounds (ADR-0005) need `source` set to the download URL, `author` to the creator, `license` to
the licence name (CC0 or CC-BY, with the credit text), and `date` to the download date. Rows owned by
the build script are replaced on each build. Other rows are kept.
