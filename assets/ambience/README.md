# Ambience assets

Beds for the ambience mixer (ADR-0005). Taxonomy ids are in `src/core/analysis/ambience-taxonomy.ts`.

- `base/`: the procedural base pack, generated by `npm run sounds:build` (`scripts/sounds/build-base-pack.mjs`).
  Checked by `npm run sounds:verify`.
- `base/manifest.json`: one row per bed.
- `LICENSES.json`: the licence ledger. Every bundled file has a row.

Regenerate the base pack only through the build script. Do not hand-edit the generated files.

## `base/manifest.json`

A JSON array. Each entry:

```json
{
  "id": "base_rain",
  "file": "base_rain.m4a",
  "durationMs": 60000,
  "loopStartMs": 0,
  "loopEndMs": 60000,
  "lufs": -27.6,
  "bytes": 493423,
  "sha256": "<64 hex chars>",
  "kind": "bed",
  "source": "procedural",
  "recipeVersion": "base-pack-v1"
}
```

`file` is relative to `base/`. `lufs` is the integrated loudness measured after normalization.

## `LICENSES.json`

A JSON array of ledger rows, one per bundled file:

```json
{
  "id": "base_rain",
  "file": "base_rain.m4a",
  "license": "Proprietary (generated in-house)",
  "source": "scripts/sounds/build-base-pack.mjs",
  "author": "Lectio",
  "date": "2026-10-11"
}
```

Sampled sounds (ADR-0005) need `source` set to the download URL, `author` to the creator, `license` to
the licence name (CC0 or CC-BY, with the credit text), and `date` to the download date. Rows owned by
the build script are replaced on each build. Other rows are kept.
